# 素材、外掛與授權政策

## 公開原則

- 專案作者顯示為 `4pins`；教師姓名／稱呼與開課單位不公開。
- 原創整理文字、圖表與工具程式採 MIT；第三方影片、商標、字型、圖片、音訊、外掛與模型不因放在本專案索引中而改為 MIT。
- YouTube 只提供連結，不把下載備份提交到 GitHub。課堂錄影依已取得的課堂同意，作免費、非營利回看用途。
- 課堂筆記圖片只搬入實際屬於該堂增量區段的 27 張；累積文件中的重複圖片不重複提交。

## AEP 公開策略

- 保留課堂練習過程版本與具代表性的最終／參考版本。
- 排除 Auto-Save、Adobe Media Encoder 暫存專案與跨堂重複副本。
- AEP 可能仍引用未嵌入的字型、圖片、影片或外掛；`manifest.json` 的 `dependency_status` 明確標為待開啟稽核。
- 影片、安裝程式與 ZIP 不提交。

## 外掛

課程使用 Saber 等第三方外掛。請由原作者官方頁取得並遵守其授權；本 Repo 不散布來源資料夾內的安裝檔。
