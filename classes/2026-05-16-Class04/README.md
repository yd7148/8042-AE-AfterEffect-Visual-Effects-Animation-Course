## 操作順序

以 Ramp 建立底色並用 Offset 流動；CC RepeTile 擴張邊界；Circle Mask 做泡泡；再逐一疊加 CC Blobbylize、Tint、CC Glass、Turbulent Displace，最後以 Map／遮色關係限制效果範圍。[播放清單](https://www.youtube.com/playlist?list=PLsEaLmxyXerCkrdW02AvU_YhA4ApTO7eU)包含 [Ramp](https://www.youtube.com/watch?v=pp0dsX_tR1M)、[RepeTile](https://www.youtube.com/watch?v=_UmYm4OwAZE)、[Circle Mask](https://www.youtube.com/watch?v=q-AMDJtQZZs)、[複合效果](https://www.youtube.com/watch?v=0WLTjIUP3eI)、[Map 遮色](https://www.youtube.com/watch?v=w-xHsbqr23I)。
