## 學習目標與操作

先用關鍵影格做出可工作的運動，再 Alt/Option 點碼表加入 expression。以 `time` 取得時間、`value` 保留原值，週期運動可用 `loopOut()`；平均分配位置時用 `index`、數量與間距計算。把速度、振幅、間距連到 Slider Control，方便統一調整。

常見錯誤是全形引號、維度不符、引用已改名圖層，或把參考網址誤貼入 expression。本堂沒有新增的老師單支影片，依完整錄影與[原始筆記](sources/original-notes.md)學習；另見[來源對照](sources/source-map.json)與[練習 AEP](aep/)。
