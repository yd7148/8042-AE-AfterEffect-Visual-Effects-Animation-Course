# Class05｜3D Logo 與 Saber 光線

日期：2026-05-23｜[完整錄影](https://www.youtube.com/watch?v=4cvvlCR2EKg)

## 操作順序

Logo 分層並開啟 3D Layer，以攝影機製造視差；建立 Null Object 並 Parent 多個圖層，集中控制旋轉與位移；最後以 Saber 的 Core Type、Glow、Distortion 建立電光輪廓。參考：[Saber Logo](https://www.youtube.com/watch?v=kaZbb5-1aws)、[建立 3D Logo](https://www.youtube.com/watch?v=T0qUGl-aTHw)、[建立控制 Null](https://www.youtube.com/watch?v=8mCkJZ3J2eo)。
