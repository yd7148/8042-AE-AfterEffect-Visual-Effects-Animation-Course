# Class01｜AE 基礎、快取與 Track Matte

日期：2026-04-18｜完整錄影：當日未開直播

## 學習目標與操作

認識素材、圖層、合成與關鍵影格；確認 Media & Disk Cache 位置並養成約每 20–30 分鐘或完成一段練習後檢查快取的習慣。建立文字／形狀與素材圖層後，練習 Position、Scale、Opacity，最後以 Alpha Track Matte 讓一個圖層控制另一圖層的可見範圍。

## 常見錯誤

- 刪除專案素材不等於清除快取。
- 遮罩圖層沒有 Alpha，或 TrkMat 指向／圖層順序錯誤。
- 未先確認合成尺寸、幀率與時長。
