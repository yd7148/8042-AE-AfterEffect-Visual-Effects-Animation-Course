# Class06｜Logo 反射光澤與商品排版

日期：2026-05-30｜[完整錄影](https://www.youtube.com/watch?v=xCtS1qukfcM)

## 操作順序

預合成與漸層底色後，用 Vegas／Glow 描邊，以 Color Offset／Bevel Alpha 做移動光跡，再加 CC Glass／Blobbylize 形成凹凸反射。商品文字先分標題、內文與重點，再安排動畫；課堂色票為 `#1D45D7`、`#2626D2`、`#15076C`。
