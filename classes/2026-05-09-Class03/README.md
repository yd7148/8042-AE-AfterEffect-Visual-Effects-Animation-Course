# Class03｜轉場效果

日期：2026-05-09｜[完整錄影](https://www.youtube.com/watch?v=7kBERVJ9_kM)

## 學習方法

把兩段素材重疊，先只做遮蔽／揭露，確認節奏後再加入模糊、縮放與緩動，最後預合成以便重用。依序練習 [Square](https://www.youtube.com/watch?v=yqFZh2ZcD_w)、[Radial Wipe](https://www.youtube.com/watch?v=05-ZkaxUP00)、[置入素材與 Directional Blur](https://www.youtube.com/watch?v=0WtJ1hx3HIE)、[Transform + Directional Blur](https://www.youtube.com/watch?v=aOhmyfgCxO4)、[Elegant Slide 01](https://www.youtube.com/watch?v=ri3gUWBadxA)／[02](https://www.youtube.com/watch?v=gf0qH_eAa8Q)，或使用[完整播放清單](https://www.youtube.com/playlist?list=PLsEaLmxyXerChuPQRf9hnPkhpj4HnOUPN)。

## 常見錯誤與檔案

素材沒有重疊會出現黑畫面；Adjustment Layer 太長會影響非轉場區；關鍵影格沒有緩動會很突兀。[原始筆記](sources/original-notes.md)｜[來源對照](sources/source-map.json)｜[練習 AEP](aep/)
